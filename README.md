# erikagaudan.github.io

Personal website for **Erika Gaudan** — Virtual Assistant with a background in Accountancy and hands-on experience supporting a remote finance team in Australia.

## Structure

- `index.html` — Single-page responsive website (Home, Services, Why Me, Experience, Tools & Software)
- `assets/css/style.css` — Soft Cream, Dusty Pink & Deep Navy responsive stylesheet
- `assets/js/main.js` — Scroll-spy navigation, reveal animations, and footer year helper
- `assets/img/profile_photo.jpeg` — Profile photo
- `manifest.json` — Web app manifest

## Deployment

Hosted via GitHub Pages from the `erikagaudan.github.io` repository.
